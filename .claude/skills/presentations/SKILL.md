# Presentations

Run `pres guide` (or `node <presentations repo>/bin/pres.mjs guide`) and follow it: it is the
single, agent-agnostic guide, `PRESENTATIONS.md` in the presentations repo. It has the house
style, the facts rules, the workflow (new → outline → draw → build → **look at the screenshots** →
check → publish) and the slide kit. `pres guide --full` adds the complete kit reference.

Don't work from memory of an earlier version: the guide is the source of truth.
